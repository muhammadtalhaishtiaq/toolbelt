# reel: brief

Ask (one message, defaults included) and write `film/BRIEF.md`:
1. **Audience** — judges, users, investors, recruiters? What do they already know?
2. **Platform and length** — hackathon (limit from RULES), YouTube, X (≤ 2:20 for most accounts), LinkedIn, vertical Shorts/Reels/TikTok (0:35 is a good default).
3. **The one feeling** after watching (e.g. "it can see what I can't").
4. **Magic moment** — the 10 seconds that make the product obvious; it must appear by ~0:40 in a 3-minute film, by 0:05 in a vertical cut.
5. **Must-show features** — each with *where it works live* (URL path + account/state needed). Read forge `docs/TASKS.md`/`STATUS.md` if present; only done features qualify.
6. **Proof** — numbers or facts you can show on screen (tests, real model calls, speed). Every one must be verifiable.
7. **Constraints** — new-work rules, brand, things not to show (keys, personal data, unfinished features).
8. **CTA** — URL, repo, "try it free", event hashtag.
