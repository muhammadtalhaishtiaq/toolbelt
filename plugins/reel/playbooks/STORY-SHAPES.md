# Story shapes

Timings are guides; the voice decides final lengths (~2.5 words/second).

## Hackathon demo — 3:00
| Time | Beat | Content |
|---|---|---|
| 0:00–0:08 | Hook | One line that names the gap ("YouTube can't see you're stuck.") over the product's best frame |
| 0:08–0:20 | Problem | The painful moment, in the user's world |
| 0:20–0:45 | Create / setup | The first real flow, fast, with ⏩ on waits |
| 0:45–1:20 | **Magic moment** | The thing nothing else does — slow down here, silence or a music hit |
| 1:20–1:50 | Second feature | Depth: another real flow |
| 1:50–2:15 | Trust / how | Safety, privacy, honest failure — shown, not told |
| 2:15–2:40 | Tech depth | The sponsor's tools by name, the pipeline as a quick diagram |
| 2:40–3:00 | CTA | Try it, code, team — end card ≥ 3 s |
Judges usually weigh impact, use of required tech, technical depth and demo quality: hit each one visibly.

## Launch — 1:30
Hook (5 s) → problem (10 s) → three feature beats (15 s each) → proof or social proof (15 s) → CTA (10 s).

## Vertical — 0:35
Magic moment first (0–5 s) → what it is in one line (5–10 s) → two quick beats (10–28 s) → CTA (28–35 s). Captions always on, one line per beat, loop-friendly last frame.

## Feature reveal — 0:20
Before (5 s) → the change, one motion hit (8 s) → after + name (7 s).
